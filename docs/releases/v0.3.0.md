## Whereabouts 0.3.0 — developer preview

*Learn.* Whereabouts now learns what each of your apps normally does, and warns you, with the reasons, when that changes.

### What it learns and warns about

For every program, Whereabouts keeps a small profile: the sites, companies, countries and ports it normally talks to, how much it normally uploads, and the hours it is usually active. An alert says what was unusual and how that compares with normal. It warns about:

- **An upload spike**: far more data sent than the program usually sends (and at least 10 MB in an hour).
- **A flip from downloading to uploading**, for a program that mostly downloads.
- **A random-looking site name**, the kind malware often uses.
- **A program file that changed** (for example, swapped for another one) and then reaches somewhere new.
- **Activity at an unusual hour**, listed on the Alerts screen without a notification.

Several signals within 10 minutes become one alert, and a warning still waiting for you is updated ("seen again") instead of repeated. On each alert you can block the app or site, **Dismiss** it (it comes back next time), or choose **This is fine**, which for random-looking names and unusual hours also stops the same warning for that app.

### When warnings start

- **Each app has a 7-day learning period**, counted from its first data. Until then it only gets the older warnings (trackers, bad networks).
- **Apps with 7 days or more of saved history start warning at once.** On the first start after the update, Whereabouts builds their profiles from that history.
- **A new site, company or country is listed but doesn't notify.** Global content networks made these too common. They are learned straight away.
- **Beaconing detection (regular check-ins to one place) is not switched on yet.** The lab found too many false alarms, so it is built but off.
- A program whose file Whereabouts can't identify is never profiled.

### What is kept

- **Profiles are kept even when "Save connection history" is off**, and when you delete saved history. They hold only the sets of sites, companies, countries and ports, plus hourly totals, encrypted on your computer. The Privacy screen and the delete dialog say so.
- A browser's profile includes the websites (registrable names only) it has used.
- **Reset** on the Apps screen clears one app's profile; **Delete everything** clears them all. If something bad was already running while an app was learning, reset that app.

### Browsers

Browsers reach new places all the time, so apps marked **Goes anywhere** get no new site, company or country signals; the other warnings stay. Real browsers, installed by administrators and signed by their publisher, are marked automatically. A file that merely has a browser's name is not. You can switch "goes anywhere" on or off for any app on the Apps screen; switching it off takes effect at once.

### How well does it work?

In the lab, with simulated users and fresh traffic that nothing was tuned on (run 45628351177), the result was **"Release bar: PASS (false alarms 0.562 ≤ 1.0; types at ≥ 50 %: 3 of 5)"**. It found random-looking domains 100 % of the time, swapped programs 100 % and hidden uploads 69 %. It does not catch renamed copies of a program (they count as new programs, still learning), and beaconing is off. 38 alerts caused only by the lab's own synthetic test entry were counted apart (before that correction the result was 2.938 false alarms, a fail). **These are lab numbers on GitHub's datacenter computers, not real-world rates.** See [section 6.2 of the design spec](https://github.com/Razni-Ahamed/Whereabouts/blob/main/docs/design-spec.md).

### Install or update

1. Download `Whereabouts_0.3.0_x64-setup.exe` and `SHA256SUMS.txt`.
2. **Check the checksum.** This preview is not code-signed yet, so Windows SmartScreen may warn:
   `(Get-FileHash .\Whereabouts_0.3.0_x64-setup.exe -Algorithm SHA256).Hash`
3. Run it and approve the administrator prompt.

**Updating from 0.2.1:** run the installer. It stops the running service, replaces the programs and starts the service again. Your history, blocks, alerts and settings are kept, and the database moves to a new layout by itself.

**Command line:** `--profile <path>` shows what was learned for a program, and `--status` says whether learning is starting, ready or paused. Resetting a profile, "goes anywhere" and "This is fine" need the Whereabouts app or an administrator terminal.

Requirements: Windows 10 22H2 or Windows 11, 64-bit.

### Known limitations

- The installer is **not code-signed** yet (signing is built in and waits for a certificate).
- A renamed copy of a program is a new program, so it is still learning and can't be caught.
- Each connection's bytes are spread evenly over the hours it lasted, so "unusual hour" is rough.
- The lab numbers above are simulated; real-world false-alarm rates may differ.
