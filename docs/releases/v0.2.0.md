## Whereabouts 0.2.0 — developer preview

*Control.* Whereabouts can now block apps, sites and addresses, warn you when something needs a look, and keep its lists up to date.

### New

- **Block what you don't want.** Next to every connection, **Block…** lets you block that site for that app, that site for every app, that address, or the whole app. Windows shows exactly what will be blocked and asks you to confirm, and **Undo** is one click. The **Rules** screen lists everything that is blocked, with **Unblock** and **Pause all blocks**.
  - Blocks are rules in the Windows firewall. They keep working when Whereabouts is closed or the computer restarts, and are kept when you update. Uninstalling removes every block.
  - Whereabouts never blocks core Windows programs, Microsoft Defender, DNS servers or your local network, so a rule can't cut your computer off.
  - If anything goes wrong, an administrator can lift every block at once: `whereabouts-service --unblock-all`.
- **Alerts.** A new **Alerts** screen tells you when an app contacts a tracker, connects to a network that Spamhaus lists as run by criminals, or when something seems to be hiding from Whereabouts, with the reason in plain words. **Dismiss** clears an alert; **This is fine** also stops alerts like it.
- **Tray and notifications.** Whereabouts can start in the tray when you sign in (you are asked once). It notifies you when an app uses the internet for the first time, when it stops watching, when blocking stays paused, about alerts, and once a day about trackers. **Notifications don't name apps or sites unless you allow it**, because Windows keeps a history of them and can show them on the lock screen.
- **List updates, only if you allow them.** Whereabouts asks before downloading anything:
  - its tracker, company, country and network lists from its GitHub releases (checked daily, digitally signed, refused if anything doesn't match);
  - Spamhaus' list of criminal networks from spamhaus.org, once a day (needed for risky-network alerts).

  They are plain downloads of public files: no ID, nothing about you. You can switch each off on the Privacy screen.
- **Better names.** Trackers hidden behind a site's own name are recognised ("via …"), and sites your computer looked up before Whereabouts started get names too.

### Install or update

1. Download `Whereabouts_0.2.0_x64-setup.exe` and `SHA256SUMS.txt`.
2. **Check the checksum.** This preview is not code-signed yet, so Windows SmartScreen may warn:
   `(Get-FileHash .\Whereabouts_0.2.0_x64-setup.exe -Algorithm SHA256).Hash`
3. Run it and approve the administrator prompt.

**Updating from 0.1:** run the installer. It stops the running service, replaces the programs and starts the service again. Your saved history is kept; apps already in it count as known, so you won't get "new app" notifications for them. Open Whereabouts afterwards: it asks whether to start in the tray and whether to download list updates.

Requirements: Windows 10 22H2 or Windows 11, 64-bit.

### Known limitations

- The installer is **not code-signed** yet (signing is being arranged).
- A site block can let the very first connection through, if it starts before Windows has looked the site up.
- Risky-network alerts need Spamhaus' list, which is downloaded only if you allow list updates.
- Browsers using DNS-over-HTTPS, and some VPNs, hide domain names from Windows, so Whereabouts shows addresses and network owners instead, and can only block those sites by address.
