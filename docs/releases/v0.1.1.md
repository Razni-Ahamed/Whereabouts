## Whereabouts 0.1.1 — developer preview

A small update to 0.1.0.

### Fixed

- **More complete self-check on the Privacy screen.** Its count of Whereabouts' own internet connections now includes the Microsoft WebView2 helper programs that draw the app's window (they run as separate processes, so 0.1.0's match by program name missed them), and identifies the app and service by process ID rather than file name. Checked on 0.1.0: these helpers made no internet connections, so 0.1.0's "Whereabouts makes no internet connections" held; now the screen would show it if that ever changed.
- `serde_with` (used inside the app framework) is at a version with no known issues.

### Install or update

1. Download `Whereabouts_0.1.1_x64-setup.exe` and `SHA256SUMS.txt`.
2. **Check the checksum** — this preview is not code-signed yet, so Windows SmartScreen may warn:
   `(Get-FileHash .\Whereabouts_0.1.1_x64-setup.exe -Algorithm SHA256).Hash`
3. Run it and approve the administrator prompt.

**Updating from 0.1.0:** run the installer; it stops the running background service, replaces the programs and starts the service again. Your saved history is kept.

Requirements: Windows 10 22H2 or Windows 11, 64-bit.

### Known limitations

- The installer is **not code-signed** yet (signing is being arranged).
- Connections that started before Whereabouts may have no domain name.
- Browsers using DNS-over-HTTPS may show addresses and network owners instead of domain names.
- No blocking, alerts or notifications yet; those come in 0.2.
