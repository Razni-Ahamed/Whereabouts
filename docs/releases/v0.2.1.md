## Whereabouts 0.2.1 — developer preview

*Security update.* A security test on 2026-11-22 found ways for other programs on your computer to get around Whereabouts in 0.2.0 and earlier, for example a blocked app unblocking itself. They are all fixed here, and the [public report](https://github.com/Razni-Ahamed/Whereabouts/blob/main/docs/reviews/security-ui-test-2026-11-22.md) explains each one. **If you use 0.2.0, please update.**

### Security fixes

- **Only the Whereabouts app, or a command line run as administrator, can change your blocks.** Before, any program could use Whereabouts' command line to pause blocking or remove a rule without asking you, so a blocked app could free itself. The same now goes for deleting history, silencing alerts and list-update settings. Reading (`--status`, `--rules`) still works without administrator rights.
- **A fake app can't pass as a real one.** A program called `chrome.exe` in any folder appeared inside real Chrome's card, with Google's name and "signed" badge, and their traffic was added up together. Now each program file has its own card and its own "Last 24 hours" totals, and programs that share a name show their folder.
- **Copies of a blocked app are blocked too.** A byte-identical copy of a blocked program in another folder could connect freely. Whereabouts now blocks such a copy with a rule of its own (shown on the Rules screen) and tells you. Its very first connection may still get through.
- **Rules are checked more strictly.** An app rule must name a real program, and a site rule can't be a shared ending such as `co.uk` or `github.io`, which would block countless sites.
- **The service takes its connection to the app back.** While the service was stopped (during an update or after a crash), another program could take its place, and the app then got no answers until a restart. The service now keeps trying and takes it back as soon as it can. A program that connects and then stays silent is let go after two minutes, so it can't hold a place forever.
- **Warnings that can't be undone default to Cancel.** Pressing Enter in "Delete everything Whereabouts saved?" or "Stop these warnings?" no longer goes ahead.

### New

- **Choose whether history is saved.** A **Save connection history** switch on the Privacy screen (asked once when you open the app). With it off, nothing finished is saved; live connections, alerts, blocking and notifications keep working. When you turn it off, Windows asks whether to keep what is saved or delete it now.
- **Much less writing to your disk.** Saving history now writes about 8 MB an hour with ordinary traffic instead of about 70 MB, and the app and saving no longer wait for each other. A crash loses nothing saved.
- **A living background.** A slowly turning globe drawn in characters: countries your apps are connected to glow, and a country flashes when an app connects there for the first time in a while (amber for trackers). It uses only what the app already shows, and it has no "you are here" marker, because Whereabouts doesn't know or guess where you are.
- **Lighter on your computer.** About a third of one processor core with the window open and about 2% minimised, down from about one core in 0.2.0. With Windows' "Animation effects" off, everything stays still.
- **Web pages inside apps are credited to the app.** Pages and ads that apps such as uTorrent Web show through Microsoft Edge WebView2 used to appear as "msedgewebview2". They now appear under the app itself, marked "web content".

### Fixed

- **A blocked app is cut off both ways**, and it no longer shows web pages from the internet (ads included) in its window.
- **"Undo" no longer removes a block you already had**, and requests are never sent twice when Whereabouts answers with an error.
- **The Block menu opens in view** on every screen, even from a long list.
- Rule numbers are never reused, Windows' own certificate checks no longer count as tracker alerts, the block dialog says what a site block can't stop, and the frosted-glass cards blur again.

### Install or update

1. Download `Whereabouts_0.2.1_x64-setup.exe` and `SHA256SUMS.txt`.
2. **Check the checksum.** This preview is not code-signed yet, so Windows SmartScreen may warn:
   `(Get-FileHash .\Whereabouts_0.2.1_x64-setup.exe -Algorithm SHA256).Hash`
3. Run it and approve the administrator prompt.

**Updating from 0.2.0:** run the installer. It stops the running service, replaces the programs and starts the service again. Your history, blocks, alerts and settings are kept, and the database switches to its new, lighter way of saving by itself. Open Whereabouts afterwards: it asks once whether to keep saving history. Blocks you already had are made to cover incoming connections too when the service starts.

**If you use the command line in scripts:** commands that change something (`--block-app`, `--unblock`, `--pause-blocking`, `--delete-all` and the like) now need an administrator terminal.

Requirements: Windows 10 22H2 or Windows 11, 64-bit.

### Known limitations

- The installer is **not code-signed** yet (signing is built in and waits for a certificate).
- A site block can let the very first connection through, if it starts before Windows has looked the site up; the same goes for the first connection of a copy of a blocked app.
- Browsers using DNS-over-HTTPS, and some VPNs, hide domain names from Windows, so Whereabouts shows addresses and network owners instead, and can only block those sites by address.
